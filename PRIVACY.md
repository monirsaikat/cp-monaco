# Privacy policy for cPanel Monaco Editor

cPanel Monaco Editor runs on cPanel File Manager editor pages. It reads and writes files through the cPanel server that you are already signed in to. File contents and file operation requests go to that server as part of editing; they are not sent to the extension developer or to an analytics service.

The extension stores settings, open tabs, unsaved drafts, saved file history, folder listings, and project indexes in your browser so those features work across visits. This data stays on your device. You can remove drafts, history, and saved lists with **Private → Delete all drafts, history and saved lists now** inside the editor. Uninstalling the extension removes its browser storage.

The extension does not collect telemetry, show ads, or load code from a remote service. Its editor page is blocked from making network requests. The content script communicates with the cPanel server using your existing browser session.
