      How your code is protected

      • Your files only go to your own server

        Files are loaded and saved through your cPanel's own File Manager API, using the login you already have. No other server is involved.

        Check it: open DevTools → Network. The only requests are to /execute/Fileman and /json-api/cpanel (File Manager functions) on your cPanel.

      • The editor can't go online

        This editor runs under a strict Content Security Policy: it can only load files packaged inside the extension, and every network request is blocked. Chrome enforces this, so it doesn't depend on our code behaving.

        Check it: content_security_policy in manifest.json sets connect-src 'none'.

      • No tracking, no remote code

        There's no analytics and no background script. Monaco and Emmet are bundled inside the extension instead of being loaded from a CDN.

      • No extra browser permissions

        The extension doesn't ask for your tabs, cookies, history or downloads. Chrome's install prompt mentions all websites only because cPanel can run on any domain. The code activates only on cPanel's file editor page.

      • Every line is readable

        The extension's own code is plain, unminified JavaScript. Open the extension folder and read content.js and editor.js.

      • Drafts and history stay in this browser

        Unsaved changes, and earlier versions of files you save, are kept in this browser's storage for the extension so you can get them back. They're never uploaded anywhere. History expires after 30 days, and a draft is removed once you save or discard it.
